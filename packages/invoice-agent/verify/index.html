    What if the agent pays it again?

    Asks the vault what it would answer if the agent that settled this invoice sent the same payment again: the same payInvoice (invoice id, vendor, payee, amount from the receipt above), simulated with a read-only eth_call at a block after the settlement. No wallet, nothing is signed or sent.

      States, as the agent's read-only MCP tool names them: paid_verified (settled, event and transfer agree, block finalized) · pending (not finalized yet, or sent and not in a block) · failed (reverted) · unknown_invoice (no settlement in this vault) · mismatch (the records disagree) · cannot_verify_now (the chain could not be read). Anything but paid_verified: do not pay again before the original transaction is checked.

      Source: packages/invoice-agent/verify in the AgentFi repository (Apache-2.0).
